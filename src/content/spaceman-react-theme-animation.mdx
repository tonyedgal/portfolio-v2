# Spaceman React Theme Animation

A React library for animated theme transitions.

## What it does

Spaceman React Theme Animation adds animated theme changes to React applications. It is the earlier package behind UI-Theme and powers the light and dark theme control on this portfolio.

## Explore the demo

The website demonstrates the package in a Vite application. The source and package documentation are available on GitHub.
