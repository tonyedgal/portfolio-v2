# Spaceman Skills

Small, composable skills for coding agents that support the Agent Skills format.

## What it does

Spaceman Skills packages repeatable development workflows as skills for coding agents. The collection covers commits, pull requests, merge conflicts, and plain-language replies.

## Using the skills

Browse the collection on skills.sh, or install it with the skills CLI:

```sh
npx skills add spacemansh/spaceman-skills
```

The repository also provides installers for macOS, Linux, and Windows.
